# Employee Management System

## Overview
A web-based Employee Management application developed using JSP, Servlets, JDBC, and MySQL, following the MVC architecture.

## Technologies
- Java
- JSP & Servlets
- JDBC
- MySQL
- HTML & CSS
- Apache Tomcat 11

## Features
- Create employee records
- View employee details
- Update employee information
- Delete employee records

## Architecture
MVC (Model-View-Controller)

## Setup
1. Import the project into Eclipse.
2. Configure Apache Tomcat.
3. Set up the MySQL database and employee table.
4. Configure JDBC connection credentials.
5. Run the application on the server.

## Key Learnings
JSP, Servlet request handling, JDBC connectivity, MVC architecture, and SQL CRUD operations.
